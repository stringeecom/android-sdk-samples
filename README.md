# Stringee Android SDK Samples

Android sample applications for integrating Stringee voice, video, conference, widget, chat, and softphone features.

## Samples

| Sample | Language | Description |
| --- | --- | --- |
| [`OneToOneCallSample`](OneToOneCallSample/) | Java | One-to-one voice/video calls using `StringeeCall` and `StringeeCall2`, including incoming calls and Call2 screen sharing. |
| [`Kotlin-OneToOneCallSample`](Kotlin-OneToOneCallSample/) | Kotlin | Kotlin version of the one-to-one voice/video call sample. |
| [`WidgetSample`](WidgetSample/) | Java | Voice/video call integration using the Stringee Android Widget. |
| [`ChatSample`](ChatSample/) | Java | Chat UI with conversations, messages, attachments, media, and location support. |
| [`Softphone`](Softphone/) | Java | Softphone application with contacts, dialing, call history, and incoming/outgoing calls. |
| [`VideoCallSample`](VideoCallSample/) | Java | Basic Stringee voice/video call integration. |
| [`VideoConferenceSample`](VideoConferenceSample/) | Java | Video conference integration using access and room tokens. |

## Requirements

- Android Studio with JDK 17
- Android SDK 36
- Android device or emulator running Android 7.0 (API 24) or later
- A [Stringee](https://stringee.com/) account
- Access tokens generated by your application server
- A Firebase project for samples that receive incoming-call push notifications

The samples use:

- Stringee Android SDK `2.1.13`
- WebRTC SDK `144.7559.09`
- Stringee Android Widget `1.1.6` in `WidgetSample`

## Project structure

Each sample is an independent Gradle project with its own Gradle wrapper. Open the sample directory directly in Android Studio.

```text
android-sdk-samples/
├── OneToOneCallSample/
├── Kotlin-OneToOneCallSample/
├── WidgetSample/
├── ChatSample/
├── Softphone/
├── VideoCallSample/
├── VideoConferenceSample/
└── gradle/
    └── coverage.gradle
```

The root `gradle/coverage.gradle` file contains the shared JaCoCo test-coverage configuration used by the sample projects. It is not an Android module and does not need to be opened or run separately.

## Getting started

### 1. Open a sample

Clone this repository and open the sample you want to run. For example:

```bash
git clone https://github.com/stringeecom/android-sdk-samples.git
cd android-sdk-samples/OneToOneCallSample
```

You can open that directory in Android Studio or build it with its Gradle wrapper.

### 2. Create an access token

Generate a Stringee access token on your application server, then enter it in the sample application.

Do not store your Stringee secret or generate production access tokens inside an Android application. See the [Stringee authentication documentation](https://developer.stringee.com/docs/client-authentication) for details.

### 3. Configure Firebase for incoming calls

Samples that test incoming calls use Firebase Cloud Messaging (FCM). Register the corresponding Android application in Firebase using its application ID:

| Sample | Application ID |
| --- | --- |
| `OneToOneCallSample` | `com.stringee.onetoonecallsample` |
| `Kotlin-OneToOneCallSample` | `com.stringee.kotlin_onetoonecallsample` |
| `WidgetSample` | `com.stringee.widgetsample` |
| `ChatSample` | `com.stringee.stringeechatuikit` |
| `Softphone` | `com.stringee.softphone` |

Download `google-services.json` and place it in the selected sample's `app/` directory:

```text
<Sample>/app/google-services.json
```

The Firebase configuration file is intentionally excluded from this repository.

### 4. Configure Google Maps for `ChatSample` (optional)

The location feature reads `MAPS_API_KEY` from a Gradle property or environment variable:

```properties
MAPS_API_KEY=your_android_maps_api_key
```

You can add it to `ChatSample/gradle.properties` or your user-level `~/.gradle/gradle.properties` file.

## Build and run

Run Gradle commands from inside a sample directory:

```bash
./gradlew assembleDebug
```

Install the debug application on a connected device:

```bash
./gradlew installDebug
```

Run unit tests and Android lint:

```bash
./gradlew testDebugUnitTest lintDebug
```

## Notes for call samples

- Use two Stringee users and two devices to test outgoing and incoming calls.
- Grant microphone, camera, notification, Bluetooth, and full-screen call permissions when requested.
- Incoming calls in the background require valid FCM configuration.
- The app stores only the last successfully connected access token for automatic reconnection.
- Screen sharing is available with `StringeeCall2` in the one-to-one call samples.
